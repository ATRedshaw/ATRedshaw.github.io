## Project Overview

This dashboard visualizes sentiment analysis results on Twitter data in real-time. It uses a pre-trained BERT model to classify tweets as positive, negative, or neutral.

## Features

- Real-time data fetching from Twitter API
- Sentiment classification using Hugging Face Transformers
- Interactive visualizations with Plotly
- Streamlit app for easy deployment
